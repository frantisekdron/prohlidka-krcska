Statická 3D prohlídka (engine FD Prohlídka): procházka bytem, minimapa, průvodce (G), fotky v 3D (I galerie, O nejbližší fotka, ← → další), přepnutí fotka ↔ vizualizace (X; vizualizace jsou ilustrační virtuální zařízení).
